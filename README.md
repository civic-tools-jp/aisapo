# あいサポ Ver.2.8.71 — 詳細画面再設計版

## 変更点
- 詳細画面の「訪問状況」と「訪問結果」を分離。
- 訪問状況は「未訪問 / 訪問済」の状態として表示。
- 「最終訪問結果」「最終訪問日」「訪問回数」「次回訪問日」を現在の状況にまとめて表示。
- 「今回の訪問を記録」は、本人・家族・不在・インターフォン・断られた・その他を訪問結果として保存。
- 新規の訪問記録は、結果にかかわらず訪問状況を「訪問済」として保存。結果は VisitHistory / lastVisitResult に分離して保持。
- 「フォロー」を「次にやること・フォロー」に整理。
- 地図の「不在」「断られた」は最新結果、「再訪予定」は次回対応であることが分かる表記へ変更。
- 一覧・地図の既存機能、党員ID検索・表示、名簿取込履歴など Ver.2.8.69 までの機能を維持。

## 導入
GitHub Pages 側のファイルをこの版で差し替えてください。
今回の変更はフロント側の表示・保存ロジック整理で、GAS Code.gs の再デプロイは不要です。


### Ver.2.8.71 修正版
- 詳細画面で上部サマリーと重複していた「現在の状況」セクションを削除。
- 訪問状況・最終結果・最終訪問・訪問回数・次回予定・支持は上部サマリーに一本化。
- 訪問履歴、今回の訪問記録、基本情報など既存機能は維持。


## Ver.2.8.71
- PC/スマホのパスワード表示アイコンをあいサポ独自UIに統一。
- パスワード非表示時は斜線入り目、表示中は開いた目に統一。
- Edge等のブラウザ標準パスワード表示アイコンを非表示にして二重表示を防止。
- ログイン、初回PW変更、通常PW変更、ユーザー追加の仮PWを同じ仕様に統一。
- 管理者/支部管理者/一般ユーザーのアイコンはPagesの現在URLを基準に相対解決。
- ロール画像の読み込みに失敗しても、壊れた画像マークではなく役割別フォールバックアイコンを表示。
