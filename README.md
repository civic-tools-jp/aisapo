# あいサポ Ver.2.8.58

Ver.2.8.58 は、Ver.2.8.57 の地上戦ダッシュボードを、現場で一目で判断しやすい情報設計に整理した版です。

- 「今日やること」は対応ありを先頭にし、0件は弱表示。対応ありには優先番号を表示。
- 活動実績の直後に「地域ごとの訪問状況」を配置。
- 訪問進捗はカードを減らし、全体残量が分かるコンパクト表示へ変更。
- 支持ランクに件数だけでなく構成比を追加。
- 「つながり」と「対応中」を分離。
- 支部連絡はダッシュボードの最後へ移動。
- GAS/APIロジックは Ver.2.8.57 から変更なし。

## Ver.2.8.58
- 活動状況の先頭に「今日やること」を追加（再訪期限超過、急ぎ、フォロー未対応、ポスター未報告、訪問注意）。
- 日次・直近7日・月次の活動実績を追加。訪問数、接触数、不在、配布、接触率を表示。
- 町丁目住所に依存した分析を廃止し、緯度経度を約500m区画に集約する地域進捗へ変更。
- 再訪優先度の入力UIを廃止し、「次回訪問日＋急ぎフラグ」中心に整理。旧データの再訪優先度列は互換性のため保持。
- 「手応え」ステータスを分析・絞り込み上の独立項目から外し、既存 good データは訪問済として扱う。
- 詳細画面上部に現在状態・最終訪問・次回予定・支持ランク・注意を要約表示。基本情報と訪問履歴は折りたたみ可能。
- 支持ランクは得票予測ではなく、登録済み情報の現在構成として表示。
- Records に urgent 列を追加。GAS 側に activitySummary API を追加。

## この版で整理したこと

- 現行画面・APIから参照されていない旧ヘルパー関数を削除
- 一時的な移行・調査・クリーンアップ関数を本番ソースに含めない方針へ統一
- `index.html` のJavaScript読込を1ファイル1行に整理
- 旧バージョン番号だけを残していたCSSコメントを削除（CSSルール自体は変更なし）
- `docs/SOURCE_STRUCTURE.md` を追加し、保守時に触る場所を明確化
- 本番スプレッドシートを9シート構成として明文化

## 現行の主な機能

- 地図中心の訪問活動管理
- 訪問履歴・再訪・支持ランク・フォロー・ポスター依頼管理
- 党員／サポーター名簿の取込
- 名簿取込時は住所を位置情報への変換にのみ使用し、住所文字列を保存しない
- 位置変換できなかった名簿データの確認・地図指定
- 一般利用者／支部管理者／県連管理者／システム管理者の権限制御
- 3時間無操作で自動ログアウト
- 支部連絡、ログイン履歴、ユーザー・活動エリア管理

## 本番スプレッドシート

以下の9シートを使用します。

- Users
- Branches
- Areas
- Contacts
- Records
- VisitHistory
- Sessions
- BranchMessages
- LoginHistory

旧 `Posters`、旧 `訪問記録`、旧 `Records_backup_*`、`町丁目マスタ` は照合・確認後に削除済みです。

## ソース構成

詳細は `docs/SOURCE_STRUCTURE.md` を参照してください。

## 更新手順

1. GitHub側をこのZIPのHTML/CSS/JavaScriptへ更新
2. Apps Scriptの `Code.gs` を `gas/Code.gs` に置換して保存
3. Webアプリを新しいバージョンとして再デプロイ
4. ログイン、地図、一覧、詳細、名簿取込、管理画面を確認

## 保守ルール

一時的な修復・調査・データ移行処理は、本番 `Code.gs` に追加しっぱなしにせず、別 `.gs` で実行して完了後に削除します。

党員ID・苗字・位置情報の組み合わせでも個人を識別し得るため、住所文字列を保存しない場合でも、権限・端末・アカウントの管理は継続して必要です。
