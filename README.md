# あいサポ Ver.2.8.55

Ver.2.8.55 は、現行機能を維持したまま旧移行コード・テスト資材・未使用画像を整理したクリーンアップ版です。

## 現行の主な機能
- 地図中心の訪問活動管理
- 訪問履歴・再訪・支持ランク・フォロー・ポスター依頼管理
- 党員／サポーター名簿の取込
- 名簿取込時は住所を位置情報への変換にのみ使用し、保存する個人情報を最小化
- 位置変換失敗時の確認・地図指定
- 一般利用者／支部管理者／県連管理者／システム管理者の権限制御
- 3時間無操作でセッション更新停止・自動ログアウト
- 支部メッセージ、ログイン履歴、ユーザー管理

## 現行スプレッドシート
以下は現行運用で使用するため削除しないでください。

- Users
- Branches
- Areas
- Contacts
- Records
- VisitHistory
- Sessions
- BranchMessages
- LoginHistory

`Posters`、`訪問記録`、`訪問記録_backup...` は旧構成のシートです。Recordsへの移行確認後に削除できます。なお、現在の「ポスター依頼」機能は Records 内で管理しているため、旧 `Posters` シートとは別です。

## スプレッドシート整理
Apps Scriptで最初に次を実行してください。

```javascript
auditV2855Cleanup()
```

これは確認専用で、データは削除しません。実行ログで `missingSheets` が空であることと、`legacySheets` の候補を確認してください。

確認後、旧シートを削除する場合だけ次を実行します。

```javascript
cleanupV2855LegacySheets('DELETE_LEGACY_SHEETS')
```

確認文字列が一致しない場合は削除しません。また、現行シート不足や Records が空の場合は安全のため中止します。

## Ver.2.8.55 のクリーンアップ内容
- 旧バージョン専用の `upgradeV...` / `migrate...` / 修復・テスト用関数を削除
- 旧バックアップ作成用関数を削除
- テスト用Excelを配布物から削除
- 未使用画像を削除
- 未使用のJavaScript状態変数を削除
- `Code.gs` を現行API・認証・Records・Contacts・管理・名簿取込・共通処理中心に整理
- 旧シート削除の前に確認できる保守関数を追加

## 更新手順
1. GitHub側のHTML/CSS/JavaScriptをVer.2.8.55へ更新。
2. Apps Scriptの `Code.gs` を `gas/Code.gs` に置き換えて保存。
3. Webアプリを新しいバージョンとして再デプロイ。
4. 通常ログイン、地図、一覧、詳細、名簿取込、管理画面を確認。
5. スプレッドシートを整理する場合は `auditV2855Cleanup()` を実行し、結果確認後にのみ削除処理を行う。

## 注意
党員ID・苗字・自宅付近の位置情報の組み合わせでも個人を識別し得ます。住所文字列を保存しない設計でも、権限管理と端末・アカウント管理は継続して必要です。
